# The Pelican Collection

Open index.html in a browser. No installation, build step, or internet connection is required. Keep animations/ beside index.html.

The gallery contains eight standalone HTML/SVG animations (four bicycle rides and four lighthouse stories). Russian interface and story text was translated into English; animation artwork and behavior were preserved. Original filenames identify the individual versions. The two files originally named pelican-lighthouse.html have distinct gallery titles; A Bad Day at the Lighthouse is packaged as animations/pelican-lighthouse-bad-day.html to preserve both. The Lighthouse Keeper also arrived as pelican-ride.html and is packaged as animations/pelican-lighthouse-keeper.html, keeping the earlier bicycle ride intact. The supplied prompt is reproduced exactly in the expandable section, without attributing it to every file.

## Publish the folder

- Cloudflare Pages: create a Direct Upload project in the dashboard and upload this folder or the ZIP. Ensure index.html is at the upload root.
- Netlify Drop: sign in and drag this folder onto the upload area.

Upload only this gallery folder or its ZIP. The package contains no account labels, private machine paths, source backups, or credentials. Hosting terms and quotas are set by each service.

Bottom narrative captions and chapter lists are hidden; playback controls and in-scene artwork remain. Embedded previews automatically fit their full content without fixed-height viewports.
